# Creative Writer (创意写作师)

**Goal**: 创作故事、剧本和叙事作品，掌握讲故事的艺术。

---

## 1. 故事结构

### 三幕结构

```markdown
## 第一幕：建置 (25%)

【开场】
- 普通世界：展示主角日常
- 吸引点：引发读者兴趣

【激励事件】
- 打破平衡的事件
- 主角面临选择

【第一幕结束】
- 主角进入新世界/接受挑战

---

## 第二幕：对抗 (50%)

【上升行动】
- 主角追求目标
- 遇到障碍和盟友
- 学习新技能/获得信息

【中点转折】
- 重大发现或转变
- 赌注升高

【危机加深】
- 反派/障碍加强
- 主角经历考验

【第二幕结束】
- 最黑暗的时刻
- 主角似乎要失败

---

## 第三幕：解决 (25%)

【高潮】
- 最终对决
- 主角运用所学

【结局】
- 解决冲突
- 新的平衡

【尾声】
- 展示改变后的世界
```

### 英雄之旅

```markdown
1. 普通世界 - 日常生活
2. 冒险召唤 - 机会/挑战出现
3. 拒绝召唤 - 犹豫/恐惧
4. 遇见导师 - 获得指引
5. 跨越门槛 - 进入新世界
6. 考验盟友敌人 - 新环境的挑战
7. 接近洞穴 - 准备最大考验
8. 磨难考验 - 面对最大恐惧
9. 获得报酬 - 赢得胜利/宝物
10. 返回之路 - 带着改变回归
11. 复活 - 最终考验
12. 带着万灵药回归 - 与世界分享所得
```

### 人物类型

```markdown
## 原型人物

1. 英雄 - 主角，经历成长
2. 导师 - 提供指引和帮助
3. 守门人 - 阻挡英雄前进
```

### 对话写作

```markdown
## 对话原则

1. 每个人物有独特说话方式
2. 潜台词比表面意思重要
3. 对话推动情节或揭示性格
4. 避免过于直白的信息传递

## 对话技巧

❌ "我很生气，因为你骗了我。"

✅ "你知道吗？"她放下杯子，声音平静得可怕，
   "我今天碰到李阳了。他说的和你说的完全不一样。"
```

## 3. 场景写作

### 场景要素

```markdown
## 每个场景必须包含

1. 目标 - 人物想要什么
2. 冲突 - 什么阻碍他
3. 灾难/转折 - 结果是什么

## 场景问题清单

- 这个场景推动了情节吗？
- 揭示了人物什么？
- 读者会感到什么情绪？
- 可以删掉这个场景吗？
```

### 开场技巧

```markdown
## 强力开场类型

1. 行动中 - 直接进入事件
2. 对话 - 引人入胜的对话
3. 悬念 - 提出问题
4. 强烈情感 - 情绪冲击
5. 独特声音 - 个性化叙述

## 示例

【行动】
子弹擦着他的耳朵飞过，他扑进了巷子。

【悬念】
如果我知道那天会发生什么，我绝不会打开那扇门。

【声音】
我叫福贵，年轻时嫖赌输掉了家产。
```

### 描写技巧

```markdown
## 五感写作

- 视觉：颜色、形状、光影
- 听觉：声音、节奏、静默
- 触觉：质感、温度、疼痛
- 嗅觉：气味、香气
- 味觉：味道

## 示例

❌ 厨房很温馨。

✅ 厨房里飘着刚出炉面包的香气，
   阳光透过黄色窗帘洒在木桌上，
   收音机里传来老歌的旋律，
   妈妈系着那条褪色的格子围裙，
   在灶台前轻轻哼着歌。

## 展示 vs 告诉

❌ 他很害怕。（告诉）

✅ 他的手开始发抖，
   喉咙里像卡了一块石头，
   每一步都觉得脚下的地板在摇晃。（展示）
```

## 4. 叙事视角

### 视角类型

| 视角 | 特点 | 适用 |
|------|------|------|
| 第一人称 | 亲密、主观 | 悬疑、成长故事 |
| 第三人称有限 | 跟随一个角色 | 大多数小说 |
| 第三人称全知 | 知道所有角色想法 | 史诗、群像 |
| 第二人称 | 读者代入感 | 互动小说 |

### 视角示例

```markdown
## 第一人称
我推开门，看到她站在窗边。我知道，一切都完了。

## 第三人称有限
他推开门，看到她站在窗边。他知道，一切都完了。

## 第三人称全知
他推开门，看到她站在窗边。他以为一切都完了，
却不知道她手中攥着两张机票。
```

## 5. 剧本格式

### 电影剧本

```markdown
场景 1. 内景 - 咖啡馆 - 白天

一家普通的咖啡馆。午后阳光透过玻璃窗洒进来。

张明（30岁，西装笔挺，表情疲惫）坐在角落，
盯着手机屏幕。

服务员走过来。

                    服务员
          先生，您点的美式。

张明头也不抬。

                    张明
          放着吧。

服务员放下咖啡，欲言又止，转身离开。

张明的手机响了。他看了一眼来电显示，
深吸一口气，接起电话。

                    张明（续）
          我知道了。我马上过去。
```

## Quick Reference

### 写作建议

```markdown
1. 先完成，再完美
2. 删掉不推动情节的内容
3. 从冲突开始
4. 展示，不要告诉
5. 每个对话都要有目的
```

### 故事问题诊断

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无聊 | 缺少冲突 | 增加障碍 |
| 不可信 | 动机不足 | 深化人物背景 |
| 混乱 | 线索太多 | 简化情节 |
| 平淡 | 高潮不够 | 提高赌注 |
| 俗套 | 没有意外 | 加入转折 |
