# Style Optimizer (风格优化师)

**Goal**: 优化文字风格，提升可读性、一致性和表达力。

---

## 1. 可读性优化

### 句子长度

```markdown
## 建议

- 中文：每句 20-40 字为宜
- 英文：每句 15-25 词为宜
- 复杂内容拆分为多句
- 避免一句话包含多个观点

## 示例

❌ 虽然这个项目的目标是为用户提供一个更加便捷的购物体验，但是由于预算限制和时间紧迫，我们不得不在功能和用户界面之间做出一些艰难的取舍，最终决定优先保证核心功能的稳定性。

✅ 这个项目旨在提供更便捷的购物体验。由于预算和时间限制，我们需要在功能和界面间取舍。最终，我们优先保证核心功能的稳定性。
```

### 段落结构

```markdown
## 黄金法则

1. 每段围绕一个中心思想
2. 段落首句点明主旨（主题句）
3. 后续句子支撑主题
4. 段落间有逻辑过渡

## 段落长度

- 短内容（社交媒体）：2-3 句
- 中等内容（博客）：3-5 句
- 长内容（论文）：5-8 句
```

## 2. 词语选择

### 简洁原则

| 冗余表达 | 简洁表达 |
|----------|----------|
| 进行研究 | 研究 |
| 做出决定 | 决定 |
| 在...的过程中 | 在...时 |
| 基本上 | （删除或具体化）|
| 非常非常 | 非常 / 极其 |

### 具体化原则

| 模糊表达 | 具体表达 |
|----------|----------|
| 很多 | 超过 1000 / 大约 80% |
| 最近 | 过去两周 / 上个月 |
| 一些 | 3-5 个 / 少数 |
| 显著提升 | 提升 30% |

### 动词优先

| 名词化 | 动词化 |
|--------|--------|
| 进行调查 | 调查 |
| 做出改变 | 改变 |
| 进行分析 | 分析 |
| 给予帮助 | 帮助 |

## 3. 一致性检查

### 术语一致

```markdown
## 规则

同一文档中，同一概念使用同一术语

❌ 用户 / 客户 / 使用者（混用）
✅ 用户（统一使用）

❌ AI / 人工智能 / 机器学习（混用）
✅ AI（统一使用，首次出现解释全称）
```

### 格式一致

```markdown
## 检查项

- 标题格式：统一使用中文或英文标点
- 列表格式：统一使用有序或无序
- 强调方式：统一使用加粗或斜体
- 代码格式：统一使用行内或代码块
- 日期格式：2024-01-15 或 2024年1月15日
```

### 语气一致

| 场景 | 语气 | 示例 |
|------|------|------|
| 技术文档 | 客观、专业 | "使用该函数可以..." |
| 营销文案 | 热情、亲切 | "你一定会爱上..." |
| 学术论文 | 严谨、正式 | "研究表明..." |
| 商业报告 | 专业、简洁 | "数据显示..." |

## 4. 逻辑与流畅

### 过渡词使用

| 关系 | 过渡词 |
|------|--------|
| 递进 | 而且、此外、更重要的是 |
| 转折 | 但是、然而、不过 |
| 因果 | 因此、所以、由于 |
| 举例 | 例如、比如、以...为例 |
| 总结 | 总之、综上所述、简言之 |

### 并列结构

```markdown
## 规则

并列项保持结构一致

❌ 我们的目标是：
- 提升用户体验
- 降低成本
- 团队更高效

✅ 我们的目标是：
- 提升用户体验
- 降低运营成本
- 提高团队效率
```

## 5. 风格模板

### 技术文档风格

```markdown
- 语气：客观、准确
- 人称：第三人称 / 无人称
- 句式：陈述句为主
- 术语：专业术语，首次出现解释
- 示例：代码示例必备
```

### 营销文案风格

```markdown
- 语气：热情、有感染力
- 人称：第二人称 "你"
- 句式：短句、感叹句
- 词汇：生动、有画面感
- 结尾：明确的行动号召
```

### 学术论文风格

```markdown
- 语气：严谨、客观
- 人称：避免第一人称
- 句式：复杂句，逻辑严密
- 术语：学术规范
- 引用：规范引用格式
```

## 7. 可读性评分

### Flesch Reading Ease (英文)

| 分数 | 难度 | 适用 |
|------|------|------|
| 90-100 | 非常容易 | 小学 |
| 80-90 | 容易 | 初中 |
| 70-80 | 较容易 | 高中 |
| 60-70 | 标准 | 大学 |
| 30-60 | 困难 | 专业 |
| 0-30 | 非常困难 | 学术 |

### 中文可读性指标

```markdown
- 平均句长：20-30 字为佳
- 平均段落：3-5 句为佳
- 专业术语：控制在 10% 以内
- 被动句：控制在 15% 以内
```

## Quick Reference

### 风格优化速查

```markdown
1. 短句优于长句
2. 主动优于被动
3. 具体优于抽象
4. 简洁优于冗余
5. 一致优于混乱
```

### 常见优化模式

| 原文模式 | 优化建议 |
|----------|----------|
| 被动句过多 | 改为主动句 |
| 句子过长 | 拆分为短句 |
| 术语不一致 | 统一术语 |
| 过渡生硬 | 添加过渡词 |
| 表达冗余 | 精简用词 |
