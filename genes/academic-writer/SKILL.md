# Academic Writer (学术写作师)

**Goal**: 撰写符合学术规范的论文、研究报告和学术内容。

---

## 1. 论文结构

### 标准学术论文结构

```markdown
1. 标题 (Title)
   - 简洁、准确、信息丰富
   - 包含关键词
   - 避免缩写（首次使用）

2. 摘要 (Abstract)
   - 200-300 字（中文）/ 150-250 词（英文）
   - 包含：背景、目的、方法、结果、结论
   - 独立成段，不分小节

3. 关键词 (Keywords)
   - 3-5 个
   - 涵盖研究主题

4. 引言 (Introduction)
   - 研究背景
   - 文献回顾
   - 研究问题/假设
   - 研究目的

5. 方法 (Methodology)
   - 研究设计
   - 样本/数据
   - 分析方法
   - 可重复性

6. 结果 (Results)
   - 客观呈现数据
   - 图表辅助
   - 统计显著性

7. 讨论 (Discussion)
   - 结果解释
   - 与现有研究比较
   - 局限性
   - 未来研究方向

8. 结论 (Conclusion)
   - 主要发现总结
   - 研究贡献
   - 实践意义

9. 参考文献 (References)
   - 按引用格式排列
```

## 2. 引用格式

### APA 格式 (第7版)

```markdown
## 期刊文章
Author, A. A., & Author, B. B. (Year). Title of article. Title of Periodical, volume(issue), page–page. https://doi.org/xxxxx

## 书籍
Author, A. A. (Year). Title of work: Capital letter also for subtitle. Publisher.

## 网页
Author, A. A. (Year, Month Day). Title of page. Site Name. URL

## 文内引用
- 单作者: (Smith, 2020)
- 双作者: (Smith & Jones, 2020)
- 三作者及以上: (Smith et al., 2020)
```

### MLA 格式 (第9版)

```markdown
## 期刊文章
Last name, First name. "Title of Article." Journal Name, vol. #, no. #, Year, pp. #-#.

## 书籍
Last name, First name. Title of Book. Publisher, Year.

## 文内引用
- (Smith 45)
- (Smith and Jones 45)
```

### GB/T 7714 格式

```markdown
## 期刊文章
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.

## 书籍
[序号] 作者. 书名[M]. 出版地: 出版社, 年份.

## 示例
[1] 张三, 李四. 人工智能研究进展[J]. 计算机学报, 2024, 47(3): 512-528.
```

## 3. 学术语言规范

### 应该使用

| 场景 | 推荐表达 |
|------|----------|
| 陈述发现 | 研究表明、结果显示、数据揭示 |
| 表达观点 | 可以认为、本研究认为 |
| 推测 | 可能、或许、似乎表明 |
| 比较 | 相比于、与...相比、区别于 |
| 结论 | 综上所述、基于上述分析 |

### 应该避免

```markdown
❌ 我觉得、我认为（主观）
❌ 很多、非常（模糊）
❌ 口语化表达
❌ 绝对化表述（一定、肯定）
❌ 感叹句、疑问句过多
```

### 学术常用句型

```markdown
## 引言
- 近年来，...领域受到广泛关注
- 然而，现有研究存在...局限性
- 本研究旨在...

## 方法
- 本研究采用...方法
- 数据来源于...
- 研究对象包括...

## 结果
- 结果表明...
- 如表/图X所示...
- 数据显示...

## 讨论
- 这一发现与...一致/不一致
- 可能的解释是...
- 值得注意的是...

## 结论
- 综上所述，本研究发现...
- 本研究的贡献在于...
- 未来研究可以...
```

## 4. 图表规范

### 表格格式

```markdown
表 X. 表格标题（位于表格上方）

| 变量 | 均值 | 标准差 | p值 |
|------|------|--------|-----|
| A | 3.45 | 0.82 | <.001 |
| B | 2.89 | 0.91 | .023 |

注：* p < .05, ** p < .01, *** p < .001
```

### 图片格式

```markdown
[图片]

图 X. 图片标题（位于图片下方）
注：数据来源于...；N = 样本量
```

## 5. 摘要写作模板

### 中文摘要

```markdown
[背景] 随着...的发展，...问题日益突出。
[目的] 本研究旨在探讨/分析/验证...
[方法] 采用...方法，对...进行研究。
[结果] 研究发现：（1）...；（2）...；（3）...
[结论] 研究表明...，对...具有重要意义。

关键词：关键词1；关键词2；关键词3
```

### 英文摘要

```markdown
[Background] With the development of..., ... has become increasingly important.
[Purpose] This study aims to investigate/examine/explore...
[Methods] Using ... approach, we analyzed...
[Results] The findings indicate that: (1)...; (2)...; (3)...
[Conclusion] The study suggests that..., which has implications for...

Keywords: keyword1; keyword2; keyword3
```

## Quick Reference

### 学术写作原则

```markdown
1. 客观性 - 避免主观判断
2. 准确性 - 数据和引用准确
3. 简洁性 - 避免冗余表达
4. 逻辑性 - 论证严密
5. 规范性 - 遵循格式要求
```

|------|------|----------|

| 引言 | 10-15% | 1000-1500字 |
| 方法 | 15-20% | 1500-2000字 |
| 结果 | 20-25% | 2000-2500字 |
| 讨论 | 25-30% | 2500-3000字 |
| 结论 | 5-10% | 500-1000字 |
