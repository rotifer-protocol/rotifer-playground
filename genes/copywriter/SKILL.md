# Copywriter (文案创作师)

**Goal**: 创作吸引人的营销文案、社交媒体内容和广告材料。

---

## 1. 平台模板

### 公众号文章

```markdown
## 结构

【标题】吸引眼球，制造好奇
【导言】3秒抓住读者，引出痛点
【正文】分段清晰，小标题引导
【结尾】总结+行动号召

## 标题公式

- 数字型：「5个方法让你...」
- 疑问型：「为什么90%的人...」
- 揭秘型：「终于有人说出...的真相」
- 对比型：「A vs B：哪个更适合你」
- 情感型：「看完这篇，我哭了...」

## 字数建议
- 标题：15-30字
- 正文：1500-3000字
- 每段：3-5行
```

## 2. 文案技巧

### AIDA 公式

```markdown
A - Attention（吸引注意）
   → 惊人事实、问题、故事

I - Interest（引起兴趣）
   → 痛点共鸣、好处预览

D - Desire（激发欲望）
   → 产品优势、社会证明

A - Action（促进行动）
   → 明确 CTA、紧迫感
```

### PAS 公式

```markdown
P - Problem（问题）
   → 描述痛点，引发共鸣

A - Agitate（加剧）
   → 放大问题，增加紧迫感

S - Solution（解决方案）
   → 提供产品/方案
```

### 4U 标题法则

```markdown
U - Urgent（紧迫）→ 限时、立即
U - Unique（独特）→ 首发、唯一
U - Useful（有用）→ 教程、方法
U - Ultra-specific（具体）→ 数字、细节
```

## 3. 转化元素

### CTA（行动号召）

```markdown
## 弱 CTA
- 了解更多
- 点击查看

## 强 CTA
- 立即抢购，限时8折！
- 免费领取，仅剩100份！
- 扫码加入，解锁福利！

## CTA 公式
[动词] + [价值] + [紧迫感]
```

### 社会证明

```markdown
## 类型

- 数字证明："已有10万+用户"
- 权威背书："XX专家推荐"
- 用户评价："98%好评"
- 媒体报道："被XX媒体报道"
- 明星同款："XX明星也在用"
```

### 稀缺性

```markdown
## 时间稀缺
- 限时24小时
- 活动倒计时

## 数量稀缺
- 限量100份
- 仅剩最后XX

## 资格稀缺
- 仅限新用户
- VIP专属
```

## 4. 情感触发

### 情绪类型

| 情绪 | 触发词 | 适用场景 |
|------|--------|----------|
| 恐惧 | 小心、警惕、避免 | 健康、安全 |
| 焦虑 | 错过、落后、out | 教育、技能 |
| 愧疚 | 对不起、亏欠 | 礼物、家庭 |
| 虚荣 | 高级、品味、格调 | 奢侈品 |
| 归属 | 我们、一起、社群 | 社区、会员 |
| 好奇 | 揭秘、真相、没想到 | 娱乐、知识 |

### 痛点挖掘

```markdown
## 5Why 法

问题：用户不买产品
Why1: 觉得贵 → 价值没传递
Why2: 不信任 → 缺少社会证明
Why3: 不紧迫 → 没有稀缺性
Why4: 不需要 → 痛点没击中
Why5: 不了解 → 内容不够吸引
```

## 5. 平台规则

### 敏感词规避

```markdown
## 禁用词
- 绝对化：最、第一、唯一
- 医疗：治愈、根治、特效
- 承诺：保证、100%、必定
- 对比：碾压、秒杀、吊打

## 替换方案
最好 → 备受好评
第一 → 领先
100%有效 → 众多用户反馈
```
