# Tone Analyzer (语气分析师)

**Goal**: 分析和调整内容语气，确保与目标受众和目的匹配。

---

## 1. 语气维度

### 正式程度

```markdown
## 非正式（Casual）

- 使用口语化表达
- 缩写和俚语
- 第一/第二人称
- 短句为主
- 例：你好啊！今天聊聊 AI 吧~

## 半正式（Semi-formal）

- 清晰但亲切
- 避免极端口语
- 可用第一/第二人称
- 例：您好，今天我们来讨论人工智能的发展。

## 正式（Formal）

- 书面语
- 第三人称
- 完整句式
- 避免缩写
- 例：人工智能技术的发展对社会产生了深远影响。

## 高度正式（Very Formal）

- 法律/学术用语
- 严格规范
- 被动语态多
- 例：经研究表明，人工智能技术已对社会各领域产生显著影响。
```

### 情感色彩

```markdown
## 积极（Positive）

- 乐观、鼓励
- 强调机会和好处
- 例：这是一个绝佳的机会！

## 中性（Neutral）

- 客观、平衡
- 不带情绪
- 例：这是一个需要考虑的选择。

## 消极（Negative）

- 警示、批评
- 强调问题和风险
- 例：这一决定可能带来严重后果。

## 紧迫（Urgent）

- 强调时间
- 激发行动
- 例：立即行动！机会稍纵即逝！
```

### 权威程度

```markdown
## 权威型

- 专家口吻
- 肯定表达
- 例：正确的方法是...

## 协作型

- 平等交流
- 引导而非指令
- 例：我们可以尝试...

## 谦逊型

- 承认局限
- 开放讨论
- 例：根据目前的研究，可能...
```

## 2. 场景匹配

### 商务场景

```markdown
## 正式报告

语气：专业、客观、严谨
避免：口语、情绪化
示例：
"本季度销售额达到 500 万元，同比增长 15%。
增长主要来自新产品线的贡献。"

## 内部邮件

语气：专业但友好
可用：适当的第一人称
示例：
"Hi 团队，附件是本周报告，请查收。
有问题随时沟通！"

## 客户沟通

语气：礼貌、专业、积极
避免：过于随意或冷淡
示例：
"感谢您的反馈。我们已收到您的意见，
会在 24 小时内给您回复。"
```

### 营销场景

```markdown
## 品牌内容

语气：与品牌调性一致
- 高端品牌：优雅、克制
- 年轻品牌：活力、潮流
- 专业品牌：权威、可信

## 社交媒体

语气：亲切、互动
可用：emoji、流行语
示例：
"周一好呀！☕ 新的一周，从一杯好咖啡开始~"

## 广告文案

语气：吸引、激发欲望
技巧：情感诉求、行动号召
示例：
"想要改变？现在就是最好的时机！"
```

### 学术场景

```markdown
## 学术论文

语气：客观、严谨、规范
避免：主观判断、情绪化
示例：
"本研究采用实验法，对比了两组数据，
结果表明两者存在显著差异（p<0.05）。"

## 学术评论

语气：批判但建设性
平衡：指出问题与肯定价值
示例：
"该研究方法具有创新性，然而样本量
可能限制了结论的普适性。"
```

## 3. 分析方法

### 语气识别指标

```markdown
## 语言特征

1. 人称使用
   - 第一人称 (我/我们) → 个人/亲切
   - 第二人称 (你/您) → 对话/互动
   - 第三人称 → 客观/正式

2. 情态动词
   - 必须/应该 → 强制
   - 可以/建议 → 温和
   - 可能/或许 → 不确定

3. 修饰词
   - 非常/极其 → 强调
   - 一些/适当 → 保守
   - 绝对/一定 → 肯定

4. 标点符号
   - ！→ 强调/兴奋
   - ？→ 疑问/互动
   - ... → 暗示/未完
```

## 4. 语气调整

### 调高正式度

```markdown
## 方法

1. 移除口语
   ❌ 其实吧，这个事儿...
   ✅ 实际上，这一问题...

2. 完整句式
   ❌ 很重要，要注意
   ✅ 这一点非常重要，需要特别关注

3. 被动语态（适度）
   ❌ 我们发现了问题
   ✅ 问题已被发现

4. 移除缩写
   ❌ couldn't, won't
   ✅ could not, will not

5. 第三人称
   ❌ 我认为
   ✅ 研究表明
```

### 调低正式度

```markdown
## 方法

1. 使用口语
   ❌ 请查阅附件中的文档
   ✅ 附件是材料，看看吧！

2. 第二人称
   ❌ 用户应该
   ✅ 你可以

3. 缩短句子
   ❌ 鉴于以上情况，我们建议采取相应措施
   ✅ 所以，我们建议这样做

4. 添加互动
   ❌ 以下是详细说明
   ✅ 接下来，带你了解具体怎么做！

5. 使用 emoji（视场景）
   ✅ 恭喜你完成了！🎉
```

### 情绪调整

```markdown
## 转积极

❌ 这个功能有很多问题
✅ 这个功能还有优化空间

❌ 你的方案不可行
✅ 我们可以考虑其他方案

## 转中性

❌ 这是一个绝佳的机会！
✅ 这是一个值得考虑的机会

❌ 后果将非常严重
✅ 可能产生一定影响

## 增加紧迫

❌ 您可以考虑购买
✅ 限时优惠，立即下单！

❌ 请尽快回复
✅ 请在今天18:00前回复
```

## 5. 常见问题

### 语气不一致

```markdown
## 表现

- 同一文档中正式和非正式混用
- 人称混乱（我→我们→本公司）
- 情绪波动（积极→消极→积极）

## 解决

1. 确定目标语气
2. 建立风格指南
3. 统一后检查
4. 请他人校对
```

### 语气与受众不匹配

```markdown
## 常见错误

| 受众 | 错误语气 | 正确语气 |
|------|----------|----------|
| 年轻用户 | 过于正式 | 活泼亲切 |
| 企业客户 | 过于随意 | 专业可信 |
| 学术读者 | 口语化 | 严谨规范 |
| 普通大众 | 术语堆砌 | 通俗易懂 |

## 解决

1. 了解目标受众特征
2. 参考同类成功案例
3. 请目标用户反馈
4. 迭代调整
```

### 语气调整速查

```markdown
更正式：移除口语、完整句式、第三人称
更亲切：使用"你"、简短句、口语化
更积极：强调好处、用"可以"代替"应该"
更紧迫：时间限制、行动号召、强调词
更权威：引用数据、专家说法、肯定语气
```
