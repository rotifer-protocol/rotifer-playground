# Fact Checker (事实核查师)

**Goal**: 验证内容中的事实、声明和来源，确保信息准确可信。

---

## 1. 核查原则

### 核心原则

```markdown
## 三重验证

每个关键事实至少需要：
1. 原始来源确认
2. 独立来源交叉验证
3. 专家/权威意见

## 怀疑态度

- 对惊人声明保持警惕
- 越不寻常的声明需要越强的证据
- 区分事实与观点
```

### 需要核查的内容

```markdown
## 必须核查

1. 统计数据和数字
2. 引用的言论
3. 日期和时间
4. 人名和头衔
5. 事件细节
6. 科学声明
7. 历史事实

## 示例问题

- "研究表明..." → 什么研究？谁做的？
- "专家说..." → 什么专家？有资质吗？
- "90%的人..." → 数据来源？样本量？
```

## 2. 来源评估

### 来源可信度层级

| 层级 | 来源类型 | 可信度 |
|------|----------|--------|
| 1级 | 原始文件、官方记录 | 最高 |
| 2级 | 学术期刊、权威机构 | 高 |
| 3级 | 主流媒体、专业报道 | 中高 |
| 4级 | 行业网站、专家博客 | 中 |
| 5级 | 社交媒体、匿名来源 | 低 |

### 来源评估标准

```markdown
## CRAAP 测试

C - Currency（时效性）
   - 何时发布/更新？
   - 信息是否过时？

R - Relevance（相关性）
   - 与主题相关吗？
   - 面向什么受众？

A - Authority（权威性）
   - 作者是谁？
   - 有什么资质？
   - 机构是否权威？

A - Accuracy（准确性）
   - 有证据支持吗？
   - 可以验证吗？
   - 有参考来源吗？

P - Purpose（目的）
   - 目的是什么？
   - 有偏见吗？
   - 是广告/宣传吗？
```

### 识别可疑来源

```markdown
## 警告信号

❌ 无作者署名
❌ 无发布日期
❌ 无参考来源
❌ 只有一方观点
❌ 情绪化语言
❌ 与权威来源矛盾
❌ 无联系方式
❌ 域名可疑
```

## 3. 数据核查

### 统计数据验证

```markdown
## 检查要点

1. 数据来源
   - 原始出处是哪里？
   - 机构是否权威？

2. 样本信息
   - 样本量多大？
   - 如何选取样本？
   - 是否有代表性？

3. 时间范围
   - 数据何时收集？
   - 是否仍然有效？

4. 定义明确
   - 指标如何定义？
   - 测量方法是什么？

## 常见数据误用

- 相关性当因果
- 样本偏差
- 选择性数据
- 误导性图表
```

### 数字验证

```markdown
## 基本验证

1. 数量级检查
   - 这个数字合理吗？
   - 与常识是否符合？

2. 计算验证
   - 百分比计算正确吗？
   - 增长率计算正确吗？

3. 单位确认
   - 单位是否正确？
   - 是否有单位混淆？

## 示例

声明："中国人口14亿"
验证：✓ 符合已知数据

声明："这家公司年增长1000%"
质疑：如此高增长需要更多证据
```

## 4. 引语核查

### 验证引语

```markdown
## 检查步骤

1. 确认发言人
   - 发言人是谁？
   - 确实说过这话吗？

2. 核对原文
   - 找到原始来源
   - 对比完整语境

3. 检查上下文
   - 是否断章取义？
   - 语境是否改变意思？

## 常见问题

- 虚假引语
- 断章取义
- 翻译错误
- 时间错误（把旧引语当新闻）
```

### 识别错误引语

```markdown
## 警告信号

- 来源模糊："有人说"
- 无法验证的私人对话
- 与已知立场矛盾
- 过于完美的措辞
- 无日期/场合信息
```

## 5. 图片/视频核查

### 反向图片搜索

```markdown
## 工具

- Google 图片搜索
- TinEye
- Yandex Images
- 百度识图

## 检查内容

1. 图片首次出现时间
2. 原始来源
3. 是否被篡改
4. 图片实际内容 vs 声称内容
```

### 视频核查

```markdown
## 检查要点

1. 元数据分析
2. 地理位置验证
3. 天气/时间验证
4. 视频帧分析
5. 音频分析

## 工具

- InVID（视频验证插件）
- YouTube DataViewer
```

## 6. 核查流程

### 标准流程

```markdown
## 步骤

1. 识别声明
   - 标记需要核查的内容
   - 区分事实与观点

2. 寻找来源
   - 找到原始来源
   - 寻找独立来源

3. 验证来源
   - 评估来源可信度
   - 检查来源动机

4. 交叉验证
   - 多个独立来源对比
   - 识别矛盾信息

5. 做出判断
   - 事实/错误/无法验证
   - 记录验证过程

6. 记录结果
   - 保存证据
   - 标注来源
```

### 核查报告模板

```markdown
## 声明核查报告

**声明内容**：[待核查声明]

**核查结果**：✓ 事实 / ✗ 错误 / ？ 无法验证

**证据来源**：
1. [来源1及链接]
2. [来源2及链接]

**分析**：
[详细分析]

**结论**：
[最终判断及理由]
```

## Quick Reference

### 快速核查问题

```markdown
1. 这是事实还是观点？
2. 来源是谁？可信吗？
3. 有独立来源验证吗？
4. 数据合理吗？
5. 有遗漏的上下文吗？
6. 是否最新信息？
```

### 常见误导手法

| 手法 | 识别 |
|------|------|
| 断章取义 | 查找完整语境 |
| 虚假来源 | 验证来源存在 |
| 过时信息 | 检查日期 |
| 选择性数据 | 查找完整数据 |
| 误导性标题 | 阅读正文 |
| 假专家 | 验证资质 |

### 核查工具速查

| 用途 | 工具 |
|------|------|
| 综合 | Snopes, FactCheck.org |
| 图片 | Google Images, TinEye |
| 视频 | InVID, YouTube DataViewer |
| 网站 | Wayback Machine, WHOIS |
| 论文 | Google Scholar, PubMed |
