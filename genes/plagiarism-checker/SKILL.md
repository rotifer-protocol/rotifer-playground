# Plagiarism Checker (查重检测师)

**Goal**: 检测内容的原创性，识别潜在抄袭，确保学术诚信。

---

## 1. 抄袭类型

### 直接抄袭

```markdown
## 定义
逐字复制他人作品而不引用

## 示例

原文：
"人工智能正在以前所未有的速度改变我们的世界。"

抄袭：
人工智能正在以前所未有的速度改变我们的世界。

正确引用：
张三（2023）指出，"人工智能正在以前所未有的速度改变我们的世界"（第15页）。
```

### 改写抄袭

```markdown
## 定义
改变词语但保留原文结构和思想，未注明来源

## 示例

原文：
"人工智能正在以前所未有的速度改变我们的世界。"

改写抄袭：
AI以史无前例的速度在改变着我们的世界。

正确转述：
张三（2023）认为，人工智能的发展速度史无前例，正深刻影响着全球。
```

### 自我抄袭

```markdown
## 定义
重复使用自己以前发表的作品，未说明

## 常见情况
- 把同一论文投多个期刊
- 重复使用之前作品的大段内容
- 将课程作业发表为学术论文

## 处理方法
- 声明之前发表过
- 获得复用许可
- 重新撰写内容
```

### 拼凑抄袭

```markdown
## 定义
从多个来源复制内容拼凑成文

## 特征
- 来自多个来源
- 可能有引用，但占比过高
- 缺乏原创分析

## 判断标准
一般要求原创内容 > 70%
```

## 2. 检测方法

### 工具检测

```markdown
## 学术查重工具

| 工具 | 覆盖范围 | 适用 |
|------|----------|------|
| 知网查重 | 中文学术文献 | 国内论文 |
| 万方 | 中文期刊/论文 | 国内论文 |
| 维普 | 中文学术资源 | 国内论文 |
| Turnitin | 英文学术文献 | 国际论文 |

## 免费工具

- Grammarly（基础查重）
- Quetext
- SmallSEOTools
- PaperRater

## 注意事项

1. 不同工具结果可能不同
2. 查重率不等于抄袭率
3. 引用部分也会被标记

```

### 人工检测

```markdown
## 检查信号

1. 风格突变
   - 文风突然变化
   - 专业程度不一致

2. 格式不一致
   - 字体变化
   - 引用格式混乱

3. 时间标记
   - 过时的引用格式
   - 与时间不符的数据

4. 搜索验证
   - 将可疑段落搜索引擎检索
   - 检查是否有完全匹配
```

## 3. 降重方法

### 合规降重

```markdown
## 方法一：理解后重写

1. 阅读并理解原文
2. 合上原文
3. 用自己的话表达
4. 核对是否准确
5. 注明来源

## 方法二：改变结构

原文结构：原因 → 现象 → 结果
新结构：结果 → 原因 → 分析

## 方法三：添加原创分析

- 加入自己的见解
- 结合其他文献讨论
- 提出新的角度

## 方法四：正确引用

直接引用 + 规范格式
```

### 错误降重

```markdown
## 禁止的方法

❌ 同义词替换
   "重要" → "关键" → "至关重要"
   本质上仍是抄袭

❌ 调整语序
   "A和B" → "B与A"
   结构未变

❌ 机器降重
   使用软件自动替换
   可能产生语病，仍算抄袭

❌ 图片替代
   把文字转成图片
   有些系统可以识别
```

## 4. 引用规范

### 正确引用示例

```markdown
## 直接引用（短）

研究表明，"人工智能将在未来十年改变30%的工作岗位"（Smith, 2023, p. 45）。

## 直接引用（长）

Smith（2023）在其研究中详细阐述了这一观点：

    人工智能技术的发展速度超出了大多数人的预期。
    在未来十年内，预计将有30%的工作岗位受到影响，
    其中一部分将被完全取代，另一部分将发生根本性
    变化。这一趋势对教育和就业政策提出了新的挑战。
    （第45页）

## 间接引用（转述）

Smith（2023）预测，人工智能将在未来十年影响约三分之一的工作岗位。
```

### 引用比例建议

```markdown
## 学术论文

| 部分 | 引用占比 | 说明 |
|------|----------|------|
| 引言 | 30-40% | 文献回顾较多 |
| 方法 | 10-20% | 引用已有方法 |
| 结果 | 5-10% | 主要是原创数据 |
| 讨论 | 20-30% | 与文献对话 |
| 总体 | 20-30% | 建议范围 |

## 不同文体

| 文体 | 引用占比 | 
|------|----------|
| 文献综述 | 40-60% |
| 实证研究 | 15-25% |
| 观点文章 | 10-20% |
| 新闻报道 | 5-15% |
```

## 5. 学术诚信

### 常见违规

```markdown
## 严重违规

1. 代写论文
2. 购买论文
3. 伪造数据
4. 篡改结果
5. 重复发表

## 后果

- 论文撤回
- 学位撤销
- 职位解除
- 学术声誉受损
- 法律责任
```

### 预防措施

```markdown
## 写作习惯

1. 从阅读开始记录来源
2. 直接摘录要加引号
3. 区分自己观点和他人观点
4. 完成后自查原创性
5. 提交前使用查重工具

## 文献管理

1. 使用引用管理软件
2. 记录完整书目信息
3. 标注页码
4. 保存原文PDF
```

## 6. 检查清单

```markdown
## Plagiarism Check Checklist

### 引用检查
- [ ] 所有直接引用都有引号
- [ ] 所有引用都有来源标注
- [ ] 引用格式正确统一
- [ ] 长引用格式正确（另起段、缩进）

### 转述检查
- [ ] 转述内容有来源标注
- [ ] 转述使用自己的语言
- [ ] 转述准确反映原意

### 原创性检查
- [ ] 使用查重工具检测
- [ ] 查重率在要求范围内
- [ ] 高相似段落已处理
- [ ] 原创分析占主体

### 参考文献
- [ ] 所有引用都在参考文献中
- [ ] 参考文献中的都被引用
- [ ] 格式统一正确
```

## Quick Reference

### 查重率标准

| 文档类型 | 通常要求 |
|----------|----------|
| 本科论文 | < 30% |
| 硕士论文 | < 20% |
| 博士论文 | < 15% |
| 期刊投稿 | < 15-20% |

### 快速自查

```markdown
1. 是否所有引用都标注了来源？
2. 是否使用了自己的语言表达？
3. 是否有未经允许的大段复制？
4. 引用比例是否合理？
5. 是否通过了查重工具检测？
```

### 引用 vs 抄袭

| 引用 | 抄袭 |
|------|------|
| 标注来源 | 不标来源 |
| 加引号（直接） | 不加引号 |
| 用自己语言转述 | 换几个词 |
| 适当比例 | 大量复制 |
| 有分析评论 | 简单拼凑 |
